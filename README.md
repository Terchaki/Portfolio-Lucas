## 📋 Sobre

Esta é a **V2 do meu portfólio pessoal**, desenvolvido com **Angular 19** e as melhores práticas de engenharia front-end. É uma aplicação moderna que apresenta:

- 👨‍💼 Minha trajetória e experiência profissional
- 🚀 Habilidades técnicas e stack de desenvolvimento
- 🛠️ Projetos destacados com descrições e links
- 🎓 Certificações e formações
- 📞 Meios de contato para oportunidades
- 🌙 Tema claro/escuro com persistência

O design é responsivo, acessível e otimizado para performance, proporcionando uma experiência excelente em todos os dispositivos.

## <a id="instalacao">💻 Como executar localmente</a>

### Pré-requisitos
- Node.js 18+ instalado
- npm ou yarn

### Passos

1. **Clone o repositório**
   ```bash
   git clone https://github.com/terchaki/Portfolio-Lucas.git
   cd Portfolio-Lucas
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**
   ```bash
   npm start
   ```
   A aplicação estará disponível em `http://localhost:4200/`

4. **Build para produção**
   ```bash
   npm run build
   ```
   Os arquivos compilados estarão em `dist/browser/`
